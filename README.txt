# AutoSpec India

A responsive, single-page Indian car specifications website built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. An internet connection is needed for the remote car photos.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a new **public** repository, for example `autospec-india`.
3. Upload `index.html` to the repository's root folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes. GitHub will show your public website address in the Pages section.

Your free address will look like:
`https://YOUR-USERNAME.github.io/autospec-india/`

## Important before publishing
- The included prices/specifications are starter examples and may be outdated or vary by variant. Verify each entry against current official manufacturer information before presenting it as fact.
- The car images are remote illustrative images and may not depict the exact model shown. Replace them with photos you own or have permission to use.
- The review cards are editorial placeholders, not genuine customer reviews or verified ratings. Replace them with authentic reviews and a transparent rating method.
- This is a front-end-only site. It does not yet have an admin panel, database, user accounts, or a form for visitors to submit reviews.
